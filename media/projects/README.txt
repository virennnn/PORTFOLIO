Drop project files in numbered folders: 01, 02, 03...
Then edit /js/projects.js and add media entries, for example:

media: [
  { type: "image", src: "media/projects/01/cover.jpg" },
  { type: "video", src: "media/projects/01/reel.mp4" },
  { type: "image", src: "media/projects/01/still-02.jpg" }
]
